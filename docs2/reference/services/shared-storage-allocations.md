# Shared Storage Allocations

EODHP needs various object stores and shared file systems, which may be allocated by Terraform, manually or automatically by the platform. For practicality and due to quotas in AWS some of these will be shared.

For shared EFS or Lustre storage we can use POSIX UIDs and GIDs to maintain a separation between different users of the file-system, such as different harvesters.

To avoid clashes and aid debugging, this page is a reference to these allocations and what they're for. Unshared storage allocated automatically via persistent volume claims is not included.

`<cluster>` means `dev`, `test`, `prod`, etc.

| Type | Name                                        | Subpath                                                     | UID/GID   | Allocation method       | Purpose and notes                                                                                                                             |
| ---- | ------------------------------------------- | ----------------------------------------------------------- | --------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| S3   | `access-log-eodhp-<cluster>`                | `AWSLogs/aws-account-id=235494775127/CloudFront/accounting` | n/a       | Terraform (Per-cluster) | CloudFront access logs. Used for billing download bandwidth.                                                                                  |
| S3   | `accounting-athena-eodhp-<cluster>`         | `athena-results`                                            | n/a       | ArgoCD (Per-cluster)    | AWS Athena query output location. Required by Athena. Used for analysing S3 access logs.                                                      |
| S3   | `resource-catalog-browser`                  | `/`                                                         | n/a       | Manual (global)         | Contains built catalogue browser Webpack artefacts. Will later move to a combined static apps bucket (EODHP-173)                              |
| S3   | `catalogue-population-eodhp-<cluster>`      | `/<harvest component name>/`                                | n/a       | ArgoCD (Per-cluster)    | Output location for catalogue harvest pipeline steps. Read by the next step in the pipeline when it receives a Pulsar message refering to it. |
| S3   | `eodhp-<cluster>-monitoring                 | ``                                                          | n/a       | Manual via CloudWatch   | Output location for Cloudwatch Synthetics Canaries data. Created by Cloudwatch when the canaries are created                                  |
| S3   | `spdx-public-<cluster>`                     | ``                                                          | n/a       | ArgoCD (Per-cluster)    | Storage location for licences referenced from ingested STAC and for SPDX licence text                                                         |
| S3   | `workflows-access-eodhp-<cluster>`          | ``                                                          | n/a       | ArgoCD (Per-cluster)    | Storage for workflow output metadata. Used by ades-fastapi. Despite the name does not store access policies.                                  |
| S3   | `user-workflows-catalogue-eodhp-<cluster>`  | ``                                                          | n/a       | ArgoCD (Per-cluster)    | Stores workflow access policies.                                                                                                              |
| S3   | `web-artefacts-<cluster>`                   | `media/`                                                    | n/a       | ArgoCD (Per-cluster)    | Stores Wagtail media files, eg images uploaded using the Wagtail editor UI                                                                    |
| S3   | `workspaces-access-control-eodhp-<cluster>` | ``                                                          | n/a       | ArgoCD (Per-cluster)    | Access policy storage for workspace file store access.                                                                                        |
| S3   | `workspaces-access-logs-eodhp-<cluster>`    | `s3/`                                                       | n/a       | ArgoCD (Per-cluster)    | Workspace object store access logs generated by AWS used for billing.                                                                         |
| S3   | `workspaces-eodhp-<cluster>`                | ``                                                          | n/a       | ArgoCD (Per-cluster)    | Workspace object stores. All workspaces share one bucket.                                                                                     |
| EFS  | workspace block store                       | `/workspaces/<workspace-name>`                              | 1000/1000 | Workspace controller    | Block storage for workspaces                                                                                                                  |

Other EFS stores are defined as Kubernetes PVs in their respective ArgoCD apps.
