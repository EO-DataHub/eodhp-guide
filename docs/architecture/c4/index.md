# C4 Model

This section presents the EO Data Hub architecture using the [C4 model](https://c4model.com/) (System Context,
Container, and detail/Component-level views), as a complement to the narrative architecture chapters in
[3. Architectural design](../architectural-design/index.md).

- [System Context](system-context.md) — the Hub, its users, and the external systems it talks to.
- [Containers](containers.md) — the Hub's main deployable services and how they interact.
- [Detail: Identity & Access Management](iam.md) — zooms into the IAM container from the container diagram.
- [Detail: Resource Catalogue & Data Access](resource-catalogue-data-access.md) — zooms into the Resource
  Catalogue & Data Access container from the container diagram.
