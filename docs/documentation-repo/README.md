This repository contains some of Telespazio's documentation about EODHP as a whole (vs an individual component) and working practices.

The Architecture Design Document in Word format is the official design documentation and should usually be consulted instead. It had been hoped that we could move the architecture documentation here so that it could be more easily used as a reference by developers but this was not possible. This repo therefore only contains:

- Documents on some specific topics which were points of discussion and where a more detailed proposed design was needed.
- An old version of the EODH Roadmap.
- Some of the early proposal for our development processes.
- Source for Mermaid and PlantUML diagrams in the ADD.
