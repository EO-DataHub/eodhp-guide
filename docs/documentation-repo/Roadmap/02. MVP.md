
# Hub Platform MVP

Given that the MVP is the next major development milestone, we have
provided further detail on the functionality which is planned to be
available for users at this stage of the platform development. The MVP
release aims to provide a platform which can be used for application
development and to illustrate early platform functionality across most
areas. Users should be able to:

- See the site design through the home page and some simple informational pages.
- Log in using a GitHub account.
- Search and browse a catalogue containing at least the datasets from
  the CEDA STAC catalog and some example workflows. Search includes
  sorting, pagination and spatiotemporal
  search.
- Access the STAC catalog over the dynamic STAC API.
- Have a personal workspace with some block and object storage.
- Use notebooks and access their workspace storage from them.
- Access their own data in their workspace store from outside the platform.
- Using files in a Git repository, add catalogue entries and connect
  additional STAC catalogs to harvest.
- Define workflows using CWL and run them using WPS / OGC API –
  Processes.
- View Sentinel 2 data in a map viewer and access it with WCS.
