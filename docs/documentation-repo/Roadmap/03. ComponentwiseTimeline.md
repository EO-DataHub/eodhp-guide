# Componentwise Timeline

This section describes an evolution of each component from the architecture that meets the capability roadmap. Capabilities generally require contributions from multiple components and so may appear in several places.

This timeline is intended to guide the selection of stories during sprint planning and represents a working assumption of the system’s evolution. The order of work will ultimately depend on the stories accepted into sprints during sprint planning.

### Resource Catalogue
